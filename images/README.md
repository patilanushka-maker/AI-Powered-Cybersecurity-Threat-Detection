# Project Images & Visual Assets

This directory is designated for visual assets, architecture diagrams, and application screenshots generated throughout the project lifecycle.

---

## Intended Contents
1. **System Architecture Diagrams**: High-level workflow charts illustrating the ingestion, feature extraction, model inference, and alert notification pipeline.
2. **Dashboard UI Screenshots**: Captures of the Streamlit intrusion detection monitoring interface and telemetry charts once implemented.
3. **Evaluation Plots**: Genuine ROC curves, Precision-Recall curves, confusion matrices, and feature importance bar plots generated during offline evaluation.

---

> **Note**: No placeholder screenshots, mock dashboards, or fabricated evaluation plots are stored here. Real assets will be added as each module is implemented and validated.

# Trained Models Directory

This directory stores serialized machine learning models and related preprocessor pipelines generated by the training workflow.

---

## 1. Storage & Version Control Policy
- **Excluded by Default**: All serialized model artifacts (`*.joblib`, `*.pkl`, `*.pickle`, `*.onnx`, etc.) are explicitly excluded from version control via `.gitignore`.
- Model files are binary artifacts, often exceeding Git size recommendations, and will be produced deterministically by running the training pipeline against validated datasets.

---

## 2. Security Warning: Serialized Model Loading
> **CAUTION: Arbitrary Code Execution Risk**  
> Deserializing untrusted Python pickle or Joblib files can lead to arbitrary code execution.  
> - **Never load untrusted models**: Only load `.joblib` or `.pkl` model artifacts generated within your own validated training pipeline or sourced from cryptographic checksum-verified repositories.  
> - Maintain checksums (e.g., SHA-256) of trained weights before deploying them to inference services or the dashboard.

---

## 3. Expected Artifacts (Post-Training)
Upon running the training pipeline (`src/train.py`), this directory will contain:
- `random_forest_baseline.joblib`: Trained Scikit-learn Random Forest classifier.
- `preprocessor_pipeline.joblib`: Fitted column transformer, scalers, and encoders (fitted exclusively on training split data).
- `model_metadata.json`: Feature names, training hyperparameters, timestamp, and git commit hash.
